# 🔺 Beecrowd 1045 — Tipos de Triângulos

Solução desenvolvida em **Java** para o exercício **1045 — Tipos de Triângulos**, da plataforma Beecrowd.

O objetivo do exercício é receber três valores, organizá-los em ordem decrescente e determinar quais características geométricas eles possuem.

---

## 📚 Objetivo

O exercício trabalha principalmente com:

- Entrada de dados;
- Variáveis do tipo `double`;
- Estruturas condicionais;
- Operadores relacionais e lógicos;
- Comparação entre valores;
- Classificação de triângulos;
- Lógica matemática.

---
